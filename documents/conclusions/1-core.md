# 核心机制基线

> `commit` 记录标签 `1-core`。该标签指向包含本文件的提交，`git rev-parse 1-core`
> 可解析为完整 SHA。同提交内的结论无法包含自身提交哈希，因此使用标签而非 SHA。

## 结论摘要

- **身份**只在跨序列化/恢复边界时值得注册。内存中直接持有原生对象即可；注册后使用严格的 `{ $ref }`，未知或重复 ID 立即失败。JSON 投影必须无损，恢复产生新对象与新作用域，不保留外部别名。
- **操作**目录值得保留为实验机制：`register/list/call` 提供统一发现、调用前检查和父子 trace。组合必须显式调用 `call`，子操作独立检查依赖、权限与副作用。它是可信代码的调用边界，不是安全沙箱。
- **经验**只有在改变下一次选择时才有价值。证据与建议分离；成功路线需有执行成功证据；失败只保留局部证据，不升级为永久规则。推荐再次失败即撤销并回退；过期或配置变化后重新探索。
- 三者不共用基类或统一图。身份与操作是候选公共机制，经验结构目前仍属于连接场景的领域策略；本轮没有足够证据把它们提升为 Core。

## 实验 1：身份与 JSON 边界

有效结果：

- 对象字段更新后，已有引用仍解析到同一对象；引用形状为严格的数据属性 `{ $ref: id }`。
- 两个机器对象及其连接引用可经 JSON 往返，在新作用域中恢复为新的对象图。
- 嵌套投影与快照/恢复结果不共享可变数据，外部修改不会穿透。
- 未知引用、重复 ID、同一对象重复注册、不可序列化投影、畸形恢复条目都是立即失败。

失败经验与成本：

- 严格 JSON 校验是本轮最显著的实现成本，换来拒绝静默数据丢失；目前没有第二种存储格式证明它应进入 Core。
- `encode`/`decode` 是可信用户代码，可抛错或产生外部副作用，作用域不能回滚这些副作用。
- 不提供自动图遍历、原子更新、自动迁移、对象删除或 ID 重命名。

## 实验 2：操作发现、组合与调用边界

有效结果：

- `list()` 只暴露元数据副本；修改发现结果不会影响目录。
- 组合操作通过显式 `call` 重新检查子操作的依赖、权限和副作用。
- trace 记录开始、成功、失败、操作名、调用 ID 与父 ID；权限拒绝时执行函数未被调用。
- 执行失败保留原错误并向外传播；替换依赖后可再次成功。

失败经验与成本：

- 元数据可能与实现漂移；运行时只能检查入口的直接声明，不能静态推导组合操作的完整权限/效果并集。
- 权限与副作用是可信代码的协作约定，不检查函数实际行为；直接调用函数、修改 context 或伪报副作用都能绕过边界。
- 不实现安全沙箱、事务回滚、自动补偿、调度器或插件生命周期。

## 实验 3：经验改变选择

有效结果：

- 经验按机器 ID、连接版本和完整有序路线匹配；地址、凭证或跳板配置变化时，调用方必须更新 `connectionRevision`。
- 首次探索按路线顺序执行；成功路线形成可撤销建议，下一次优先尝试，减少已知失败探索。
- 推荐路线再次失败时立即撤销该建议并继续其他路线；全部失败仍保留证据后抛错。
- JSON 恢复后的经验仍可指导执行；过期后重新探索，旧失败不能否定新的成功。

证据表（模拟执行）：

| 阶段 | 实际路线 | executor 调用次数 |
| --- | --- | ---: |
| 首次探索 | direct 失败 → via-jump 成功 | 2 |
| JSON 恢复经验后重复 | via-jump 成功 | 1 |
| 有效期过后，模拟直连已修复 | direct 成功 | 1 |

失败经验与成本：

- 目前追加每次执行记录并线性检索；数组增长由调用方清理，没有并发协调、签名认证、跨来源信任融合、置信度评分或专门索引。
- 经验 JSON 来自可信调用方，“结构上有成功证据”并不防伪；错误文本可能包含敏感信息，生产持久化前需要领域脱敏。
- 本轮没有案例支持通用经验 API，不把该结构提升为 Core。

## 跨实验组合

`tests/3-exp/demo.test.js` 的组合用例同时使用身份作用域、操作目录与经验策略，实际验证：

1. 首次 `machine.report` 经 `direct` 失败后改用 `via-jump`。
2. JSON 恢复经验后只尝试 `via-jump`。
3. 有效期过后、直连修复时重新尝试 `direct`。
4. 权限拒绝在进入 executor 前发生，失败沿父子调用链记录。

## 未决问题与下一步

- 增加一个非机器案例（例如本地文件转换），检验身份作用域与操作目录是否仍减少重复代码。
- 对比直接模块调用与注册入口的实际元数据负担；若没有新压力，不扩展经验 API。
- Schema 演化先用显式 `decode` 迁移做第二个实例，再判断是否需要共享迁移机制。
- 明确不实现：通用实体/关系 Schema、强制对象图、自动响应式更新、永久变化历史、向量检索、插件框架、透明 Proxy 注册、自动权限推导、安全沙箱。
